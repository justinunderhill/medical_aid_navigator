# Session handover — 1 October 2026

## User direction

The user found the app laborious to navigate and requested an upfront AI concierge
named MAN (Medical Aid Navigator), with concise answers grounded in app information
and uploaded medical aid benefits plans. The user approved the implementation and
asked to commit it. Commit: `2265b3e`.

The user then asked about Google Play readiness. We assessed this as a working web
MVP suitable for user testing, not yet ready for a public Play Store submission.
The user asked to pause future upgrades, preserve context, verify mobile usage,
and push the changes to trigger the existing Vercel deployment.

## Implemented

- MAN on the home page, `/man`, and `/cover`, plus desktop/mobile navigation.
- Conversation context survives client-side navigation; the most recent six
  exchanges go to the configured AI provider. No chat database or browser persistence.
- Optional benefits PDF (4 MB; provider maximum 100 pages), processed by Anthropic
  with page citations. PDF is resent on each question, not permanently learned.
- Document changes/removal reset chat; refresh clears session memory.
- App-grounded general answers, allowlisted app destinations, emergency interception,
  request size validation, output validation, uncached API responses, timeout/error UI.
- Privacy explanation covers AI processing and provider retention limitations.
- Mobile release polish: composer precedes suggested questions, install banner hides
  while editing, safe-area viewport enabled, touch targets strengthened, and useful
  connection/provider failure guidance.
- Fixed follow-up answers that contained unescaped quotes by constraining Anthropic
  responses to a JSON schema; prior assistant turns also use the same JSON format.
- Added `scripts/release-smoke.mjs` for explicit live checks with synthetic data.

## Validation baseline

- 72 unit/request tests passed, TypeScript/lint passed, production build passed.
- Live general answer and follow-up verified; conversation survived navigation.
- Synthetic PDF returned exact MRI limit, co-payment and authorisation requirement
  with page-one citations. No personal document used for this test.
- Release smoke checks passed locally: all public pages and ten scenario routes,
  404 handling, health endpoint, install manifest/icons/service worker, MAN follow-up,
  both PDF endpoints, invalid PDF rejection, emergency interception, live classification
  and checklist generation. Core pages were checked for overflow at 320px.
- These checks do not establish accuracy for every benefits guide or physical device.
