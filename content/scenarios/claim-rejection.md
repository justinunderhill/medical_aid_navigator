# Scenario: Claim Rejection

_Last reviewed: 2026-06. Source: scheme-neutral public guidance._

Key navigation points:
- Get the written reason for the rejection.
- Verify ICD-10 and procedure codes with the provider (common error source).
- Check whether authorisation was required/obtained.
- Check whether a network/DSP rule applied.
- If it was an admin/coding error, ask the provider to correct and resubmit.
- Follow the scheme's internal dispute process, in writing, before external escalation.

Do not make accusations without written reasons. Outcomes cannot be guaranteed.
